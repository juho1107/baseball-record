# DUGOUT — 사회인야구 통합 기록

게임원과 유니크플레이에서 수집한 썬볼·레드포니즈의 실제 기록을 보여주는 반응형 선수 기록 대시보드입니다. 회원가입이나 개인 외부 서비스 연결 없이 팀별 선수 목록과 개인 통합 기록을 확인할 수 있습니다.

## 게임원 기록 연결

게임원은 개인 URL 연결 대신 공개 팀 명단을 기준으로 썬볼(`club_idx=4901`)과 RedPonies(`club_idx=15680`) 전체 선수를 중앙 동기화합니다. 앱을 실행한 상태에서 다음 명령을 사용합니다.

```bash
npm run sync:gameone:teams
```

성공한 선수 기록은 `.data/gameone-snapshot.json`에 보존되며, 다음 실행에서는 실패하거나 새로 등록된 선수만 요청합니다. 게임원의 요청 제한이 감지되면 즉시 중단하고 다음 실행에서 이어받습니다.

1. 대시보드에서 `내 기록 연결`을 선택합니다.
2. 이메일, 이름, 대표 소속팀을 입력합니다. 등번호는 팀마다 다를 수 있어 기본 프로필에는 저장하지 않습니다.
3. `https://gameone.kr/locker/record/sum?group_code=...` 형식의 본인 선수 URL을 입력합니다.
4. `기록 가져오기`를 누르면 서버가 공개 페이지의 모든 공식 시즌을 조회합니다.
5. `타자 기록 / 투수 기록`, `전체 팀 / 소속팀`, `통산 / 연도별`을 조합해 확인할 수 있습니다.

통산 타율과 OPS는 연도별 비율을 단순 평균하지 않고 타수, 안타, 루타, 볼넷, 사구, 희생플라이 합계로 다시 계산합니다. 통산 방어율은 투구 이닝을 기준으로 가중 계산합니다.

팀별·연도별 기록은 공개 경기 목록에서 각 경기의 박스스코어를 가져와 원자료로 저장한 뒤 다시 계산합니다. 타자 기록은 타수, 안타, 2루타, 3루타, 홈런, 볼넷, 사구, 희생플라이를 이용해 타율과 OPS를 계산합니다.

게임원 동기화 대상은 `썬볼`과 `RedPonies`로 제한합니다. 게임원의 `RedPonies`는 `레드포니즈`로 저장하여 유니크플레이의 같은 팀과 통합할 수 있게 합니다.

투수 기록은 경기별 결과, 이닝, 피안타, 볼넷, 탈삼진, 자책점을 합산해 승패, 방어율과 WHIP를 계산합니다. 사회인야구 기준에 맞춰 방어율은 7이닝 기준이며, `전체 팀` 기록도 선택된 두 팀의 박스스코어만 합산합니다.

현재 회원 프로필은 MVP 단계로 브라우저 `localStorage`에 저장됩니다. 실제 서비스 배포 단계에서는 호스팅 인증과 서버 데이터베이스로 교체해야 합니다. 게임원 비밀번호는 수집하거나 저장하지 않습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 여세요.

## 유니크플레이 팀 관리자 동기화

감독 또는 총무가 직접 로그인하여 관리 팀의 팀원 기록을 한 번에 가져옵니다. 비밀번호와 로그인 토큰은 저장하지 않으며, 기록 결과만 `.data/uniqueplay-snapshot.json`에 저장합니다.

```bash
npm run sync:uniqueplay
```

열린 Edge 창에서 로그인한 다음 터미널에서 가져올 팀 번호를 선택하세요. 일주일마다 같은 명령을 다시 실행하면 스냅샷이 갱신됩니다. 현재는 로컬 MVP이므로 컴퓨터가 꺼진 동안 자동 실행되지는 않습니다.

대시보드의 내 기록 영역에서는 `통합 / 게임원 / 유니크플레이`, `전체 팀 / 팀별`, `통산 / 연도별`, `타자 / 투수`를 각각 전환할 수 있습니다. 통합 기록의 타율·OPS·방어율·WHIP는 두 출처의 원자료를 더한 뒤 다시 계산합니다.

썬볼과 레드포니즈에는 동명이인이 없다는 운영 기준에 따라 공백을 제거한 선수 이름을 내부 통합 식별자로 사용합니다. 게임원에서 같은 선수가 팀별로 서로 다른 `group_code`를 사용해도 이름이 같으면 한 선수로 합산합니다.

썬볼과 레드포니즈를 바로 갱신하려면 다음 명령을 사용합니다.

```bash
npm run sync:uniqueplay:teams
```

## 배포용 빌드

```bash
npm run build
```

게임원 수집 API를 포함하므로 Node.js 서버로 실행해야 합니다.

## 유니크플레이 자동 로그인

`.env.example`을 참고해 프로젝트 루트에 `.env.local`을 만들고 관리자 계정을 입력합니다.

```env
UNIQUEPLAY_LOGIN_ID=유니크플레이_이메일
UNIQUEPLAY_LOGIN_PASSWORD=유니크플레이_비밀번호
```

`.env.local`은 Git에서 제외되며 계정값은 결과 JSON이나 콘솔에 기록하지 않습니다. 로그인 세션은 `.data/uniqueplay-session`에 보관해 재사용하고, 만료되면 환경변수의 계정으로 자동 로그인합니다. 환경변수가 없으면 기존처럼 Edge 로그인 창을 띄우는 수동 방식으로 동작합니다.

썬볼·레드포니즈 전체 기록, 유니크플레이 최근 경기, 네 사이트의 최신 경기 비교를 순서대로 갱신하려면 다음 명령을 실행합니다.

```bash
npm run sync:uniqueplay:auto
```
